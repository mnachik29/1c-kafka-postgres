# Скриншоты

Сняты на рабочем стенде: платформа 8.3.27.2342 (версия для разработчиков), Apache 2.4.69 Win32,
публикация `/demo1c`.

| Файл | Что на нём |
|---|---|
| `03-odata-counterparties.png` | Ответ стандартного OData 1С: `…/standard.odata/Catalog_Контрагенты?$format=json` через Apache |
| `03b-odata-metadata.png` | `…/standard.odata/$metadata`: в состав OData входят оба справочника с реквизитом `ДатаИзменения` |
| `04-counterparties.png` | Список контрагентов в 1С:Предприятии: 6 элементов, ИНН/КПП, форма собственности, дата изменения (UTC) |
| `05-ownership-forms.png` | Список форм собственности: ООО, ИП, АО, ПАО |

Скриншоты Kafka UI лежат в [docs/screenshots](../../docs/screenshots).

Скриншотов Конфигуратора (дерево конфигурации, диалог «Публикация на веб-сервере») нет: публикация
выполнена `webinst.exe` (см. `scripts/1c.ps1 publish`), а структура конфигурации есть в `1c/src`.
